Course: ENGR 221

Description

This lab implements a Snake game that uses Breadth-First Search (BFS) and Depth-First Search (DFS) to navigate toward food automatically.

File Descriptions

* game_data.py: Manages the game board, player movement, food, scoring, and AI pathfinding.
* search_structure.py: Implements Stack and Queue classes used for DFS and BFS.
* cell.py: Defines the cells that make up the game board.
* controller.py: Controls the game and handles user input.
* display.py: Displays the game graphics.
* preferences.py: Stores game settings and configurations.
* answers.txt: Contains written answers and pseudocode for the lab.
* images/: Contains graphical assets used in the game.
* tests/: Contains testing files for the lab.

Modified Files

* game_data.py: Implemented AI pathfinding using BFS and DFS.
* search_structure.py: Implemented Stack and Queue operations.
* answers.txt: Added answers to the lab questions and pseudocode.

How to Run

1. Install Python and Pygame.
2. Open a terminal in the Lab04 folder.
3. Run python3 controller.py.
4. Use the game controls to play manually or activate AI mode.
