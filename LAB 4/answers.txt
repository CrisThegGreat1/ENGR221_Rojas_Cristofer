A. When you add an item to a stack, where should it be added?

An item should be added to the beginning of the stack. This is because stacks follow 
the Last In, First Out (LIFO) principle, meaning the most recently added item is the first 
one to be removed. By adding new items at index 0, they become the first items 
available for removal.

B. When you remove an item from a stack, which item should be removed?

An item should be removed from the beginning of the stack. Since stacks operate using 
the LIFO principle, the most recently added item must be removed first. 
Removing from index 0 ensures that the last item added is the first one taken out.

C. When you add an item to a queue, where should it be added?

An item should be added to the end of the queue. This is because queues follow the 
First In, First Out (FIFO) principle, meaning the first item added should be the first one 
removed. Adding new items to the end allows older items to remain at the front of the 
queue.

D. When you remove an item from a queue, which item should be removed?

An item should be removed from the beginning of the queue. Since queues operate
using the FIFO principle, the item that has been waiting the longest should be removed 
first. Removing from index 0 ensures that items leave the queue in the same order they
were added.

Part 3: get_first_cell_in_path() Pseudocode

1. Start at the cell containing the food.
2. Store this cell as the current cell.
3. While the current cell's search parent is not the player:
   - Move backward to the current cell's search parent.
4. Once the search parent is the player, stop.
5. Return the current cell as the next cell the player should move into.


Part 3: Compare BFS and DFS

A. What happens when you run AI mode with DFS? Explain why the player behaves in this way.

When AI mode uses Depth-First Search (DFS), the player may take longer and less direct routes to reach the
food. This happens because DFS uses a stack, which follows the Last In, First Out (LIFO) principle.
  Instead of exploring all nearby cells first, DFS follows one path as far as possible before exploring 
  other paths. As a result, the player may travel around the board rather than taking the shortest route
 to the food.

B. Will DFS or BFS find a shorter path to a food? Why?

Breadth-First Search (BFS) will find the shortest path to the food in this game because it explores neighboring
 cells one level at a time. BFS uses a queue, which follows the First In, First Out (FIFO) principle. 
 This allows BFS to examine nearby cells before moving farther away. Since each movement between cells 
 has the same cost, BFS guarantees the shortest available path to the food, while DFS does not.
